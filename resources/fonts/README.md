# IBM Plex Sans Arabic for PDF exports

`IBMPlexSansArabic-Regular.ttf` (400) and `IBMPlexSansArabic-SemiBold.ttf` (600) are embedded in the statement
PDFs by mPDF, the same family the app uses. Built from the `@fontsource/ibm-plex-sans-arabic` 5.3.0 Arabic and
Latin subsets (WOFF → TTF and merged with fontTools), with the GDEF MarkGlyphSets removed because mPDF does not
support them. Licence: SIL Open Font License 1.1 (`OFL.txt`).
