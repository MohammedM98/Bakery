# Cairo for PDF exports

`Cairo-Regular.ttf` (400) and `Cairo-SemiBold.ttf` (600) are embedded in the statement PDFs by mPDF.
Built from the `@fontsource/cairo` 5.3.0 Arabic and Latin subsets (merged with fontTools), with the GDEF
MarkGlyphSets removed because mPDF does not support them. Licence: SIL Open Font License 1.1 (`OFL.txt`).
