# لقطات التصميم المعتمد (الجلسة 8)

كل صفحة بثلاث لقطات: `-dl` سطح المكتب فاتح (1440×900)، `-dd` سطح المكتب داكن، `-m` الجوال 375px (الصفحة كاملة). اللقطات `-md` جوال داكن.
النوافذ (`dialog`) هي الطريقة الأساسية للإضافة والتعديل: الزبون، الموظف، المخبز، البيع، الإيداع، الدفعة، التسوية، البنك.
البيانات تجريبية (أسبوعان من المبيعات والإيداعات والدفعات) أُدخلت عبر الـ Actions نفسها.
