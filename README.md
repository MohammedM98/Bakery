# نظام إدارة المخابز (Bakery Management System)

منصة SaaS متعددة المخابز مبنية بـ Laravel، تتيح لمالك المنصة إضافة مخابز متعددة وإدارة اشتراكاتها الشهرية، ولكل مخبز لوحة تحكم خاصة لتسجيل المبيعات اليومية، إدارة العملاء، ورصيد القمح مقابل الخبز.

## المزايا

- تسجيل المبيعات اليومية والمقبوضات، مع تتبع مبيعات الخبز بالكيلو من لوحة تحكم واحدة.
- بيع الخبز مقابل القمح: يمكن للعميل تزويد المخبز بالقمح والحصول على خبز على دفعات، برصيد يُخصم تلقائيًا وسعر خاص يحدده صاحب المخبز.
- حالة دفع لكل عملية بيع (مدفوع / غير مدفوع) مع إمكانية تأكيد الدفع لاحقًا ورسالة تأكيد فورية.
- إدارة كاملة للعملاء (إضافة، تعديل، حذف مع كامل سجلاتهم) — الاسم ورقم الجوال.
- مالك المنصة يضيف مخابز متعددة، ولكل مخبز حساب دخول خاص (بريد إلكتروني وكلمة مرور) ولوحة تحكم منفصلة.
- اشتراك شهري لكل مخبز يجدده مالك المنصة يدويًا؛ يُمنع الوصول للوحة التحكم تلقائيًا عند انتهاء الاشتراك.
- واجهة عربية بالكامل مع دعم الاتجاه من اليمين لليسار (RTL).

## المتطلبات

- PHP 8.4+
- Composer
- Node.js + npm
- MySQL (للإنتاج) — يعمل المشروع محليًا أيضًا على SQLite بدون إعداد إضافي.

## الإعداد المحلي

```bash
composer install
npm install

cp .env.example .env
php artisan key:generate

# إعداد قاعدة البيانات: MySQL (الافتراضي في .env.example) أو SQLite للتجربة السريعة
# لاستخدام SQLite بدلاً من MySQL:
#   DB_CONNECTION=sqlite
#   touch database/database.sqlite

php artisan migrate --seed
npm run build

php artisan serve
```

### بيانات دخول تجريبية (من الـ Seeder)

| الدور | البريد الإلكتروني | كلمة المرور |
|---|---|---|
| مالك المنصة | `admin@bakery.test` | `password` |
| صاحب مخبز (مخبز النور) | `owner@bakery.test` | `password` |

> غيّر كلمات المرور هذه فورًا في أي بيئة إنتاج حقيقية.

## البنية التقنية

- **Laravel 13** + **Laravel Breeze** (Blade + Tailwind) للمصادقة.
- تعدد المخابز عبر عمود `bakery_id` مع تحقق صريح في كل متحكم (Controller) على ملكية السجلات.
- الأدوار: `super_admin` (مالك المنصة) و `bakery_owner` (صاحب مخبز)، مفروضة عبر Middleware باسم `role`.
- Middleware باسم `subscription.active` يمنع الوصول للوحة تحكم المخبز عند توقف الاشتراك ويوجّه لصفحة "الاشتراك غير مفعّل".
- الترجمة العربية لرسائل التحقق والمصادقة موجودة في `lang/ar`.
